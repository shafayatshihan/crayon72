## Attached: Equation Sheet (p4-6)

**Specific heats:** $c_P = \left(\dfrac{\partial h}{\partial T}\right)_P = T\left(\dfrac{\partial s}{\partial T}\right)_P$ ; $c_V = \left(\dfrac{\partial u}{\partial T}\right)_v = T\left(\dfrac{\partial s}{\partial T}\right)_v$

**Degeneracies:** $g_{rot} = 2J+1$, $g_{vib} = 1$

**Rigid rotator, harmonic oscillator:**
- $\dfrac{\varepsilon_{rot}}{hc} = F(J) = B_e J(J+1)$ ; $\dfrac{\varepsilon_{rot}}{k_B} = \theta_{rot} J(J+1)$ ; $\dfrac{\varepsilon_{vib}}{hc} = G(v) = \omega_e\left(v+\tfrac12\right)$
- $\dfrac{\varepsilon_{vib}}{hc} = G(v) = \omega_e\left(v+\tfrac12\right)$, $\dfrac{\varepsilon_{vib}}{k_B} = \theta_{vib}\left(v+\tfrac12\right)$ (ZPE included)
- $\dfrac{\varepsilon_{vib}}{hc} = G(v) = \omega_e v$, $\dfrac{\varepsilon_{vib}}{k_B} = \theta_{vib} v$ (ZPE not included)

**Characteristic temperatures:** $\theta_{rot} = \dfrac{hc}{k_B}B_e$ ; $\theta_{vib} = \dfrac{hc}{k_B}\omega_e$ ; $\dfrac{hc}{k_B} = 1.439\ \dfrac{\text{K}}{\text{cm}^{-1}}$

**Boltzmann relation:** $S = k_B \ln(W_{tot}) \cong k_B \ln(W_{mp})$

**Number of particle arrangements:** $W_{j,FD} = \dfrac{g_j!}{N_j!\,(g_j - N_j)!}$ ; $W_{j,BE} = \dfrac{(N_j + g_j - 1)!}{N_j!\,(g_j - 1)!}$

**Number of microstates in a macrostate:**
- $\ln(W_{m,CMB}) = \sum_j\left[N_j \ln\left(\dfrac{g_j}{N_j}\right) + N_j\right] = N + \sum_j N_j \ln\left(\dfrac{g_j}{N_j}\right)$
- $\ln W_{m,FD} = \sum_j\left[N_j \ln\left(\dfrac{g_j - N_j}{N_j}\right) - g_j \ln\left(\dfrac{g_j - N_j}{g_j}\right)\right]$
- $\ln W_{m,BE} = \sum_j\left[N_j \ln\left(\dfrac{g_j + N_j}{N_j}\right) + g_j \ln\left(\dfrac{g_j + N_j}{g_j}\right)\right]$

**Partition function, Boltzmann distribution relations (microcanonical ensemble):**
- $Z = \sum_j g_j \exp(-\varepsilon_j/k_BT)$, $N_j = N\dfrac{g_j\exp(-\varepsilon_j/k_BT)}{Z}$, $g_j$ = level degeneracy; $N = \sum_j N_j$, $E = \sum_j N_j\varepsilon_j$
- $Z_{trans} = \mathcal{V}\left(\dfrac{2\pi m k_B T}{h^2}\right)^{3/2}$
- $Z_{rot} = \dfrac{1}{\sigma}\left(\dfrac{T}{\theta_{rot}}\right)$ for rigid rotator, $T \gg \theta_{rot}$; $\sigma = 2$ for homonuclear molecule, $\sigma = 1$ for heteronuclear molecule
- $Z_{vib} = \dfrac{\exp(-\theta_{vib}/2T)}{1 - \exp(-\theta_{vib}/T)}$ [with zero-point energy included in $G(v)$]
- $Z_{vib} = \dfrac{1}{1 - \exp(-\theta_{vib}/T)}$ [without zero-point energy included in $G(v)$]
- $Z_{nuc} = (2I_A+1)(2I_B+1)$ molecule AB, nuclear spins $I_A$, $I_B$; $Z_{nuc} = (2I_A+1)$ atom A, nuclear spin $I_A$

**Statistical thermodynamic property calculations: CMB statistics**
- $E = U = Nk_BT^2\left[\dfrac{\partial(\ln Z)}{\partial T}\right]_{\mathcal V}$
- $E_{trans} = U_{trans} = \tfrac32 Nk_BT$
- $E_{rot} = U_{rot} = Nk_BT$ for rigid rotator, $T \gg \theta_{rot}$
- $E_{vib} = U_{vib} = Nk_B\left[\dfrac{\theta_{vib}}{2} + \dfrac{\theta_{vib}}{\exp(\theta_{vib}/T)-1}\right]$ (zero-point energy included)
- $E_{vib} = U_{vib} = \dfrac{Nk_B\theta_{vib}}{\exp(\theta_{vib}/T)-1}$ (zero-point energy not included)
- $P = Nk_BT\left[\dfrac{\partial(\ln Z)}{\partial \mathcal V}\right]_T$ ; for an ideal gas $P\mathcal V = Nk_BT$, $P\bar v = R_uT$, $R_u = N_{Avogadro}k_B$
- $S = k_B\ln(W_{tot}) \cong k_B\ln(W_{mp})$
- $S = Nk_B\left[\ln\left(\dfrac{Z}{N}\right) + T\left(\dfrac{\partial \ln Z}{\partial T}\right)_{\mathcal V} + 1\right] = Nk_B\left[\ln\left(\dfrac{Z}{N}\right)+1\right] + \dfrac{E}{T}$
- $S_{trans} = Nk_B\left[\ln\left(\dfrac{Z_{tr}}{N}\right) + T\left(\dfrac{\partial\ln Z_{tr}}{\partial T}\right)_{\mathcal V}+1\right] = Nk_B\left[\ln\left(\dfrac{Z_{tr}}{N}\right)+1\right]+\dfrac{E_{tr}}{T} = Nk_B\left\{\tfrac52\ln T - \ln P + \ln\left[\left(\dfrac{2\pi m}{h^2}\right)^{3/2}k_B^{5/2}\right] + \tfrac52\right\}$
- $S_{int} = Nk_B\left[\ln Z_{int} + T\left(\dfrac{\partial\ln Z}{\partial T}\right)_{\mathcal V}\right] = Nk_B\ln Z_{int} + \dfrac{E_{int}}{T}$

**Constants and conversion factors (p6):**
